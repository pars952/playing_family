# Playing Family — бэкенд для планирования детского досуга

Сервис для генерации планов досуга с использованием DeepSeek AI.

## Технологии
- Python 3.11
- Flask
- Gunicorn
- DeepSeek API

## Переменные окружения
- `DEEPSEEK_API_KEY` — ключ для доступа к DeepSeek API

## Локальный запуск
```bash
pip install -r requirements.txt
python app.py
